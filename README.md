# Kunal Sarkar Portfolio 

A responsive React + Vite portfolio for Kunal Sarkar, a BCA student at BPPIMT, Salt Lake.

## Sections Included

- Hero / Introduction
- About
- Education
- Skills
- Projects
- Contact

## Run Locally

```bash
pnpm install
pnpm dev
```

You can also use:

```bash
pnpm start
```

## Build

```bash
pnpm build
```

## Customize Quickly

- Edit content in src/App.jsx
- Update style theme in src/App.css and src/index.css
